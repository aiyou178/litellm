# AIYou LiteLLM

This is the **1.109.1 HTTPX2 patch release** of the AIYou LiteLLM
distribution. It carries the upstream LiteLLM 1.109.1 release surface with the
HTTP runtime migrated to `httpx2[http2]`, compatibility bridges for injected
legacy HTTPX clients and transports, and OpenAI Python SDK 3+ support.

- Package: [aiyou-litellm](https://pypi.org/project/aiyou-litellm/)
- Source branch: [litellm_httpx2_migration](https://github.com/aiyou178/litellm/tree/litellm_httpx2_migration)
- Formal README: [BerriAI/litellm README](https://github.com/BerriAI/litellm#readme)

For complete LiteLLM installation, SDK, proxy, and operations documentation,
read the formal README in the original repository linked above.
